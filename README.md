# Super Shop Management System

## Project Overview

Super Shop Management System is a proposed software system
designed to manage products, inventory, sales, employees,
customers, and other store management activities.

## Project Documentation

- Software Requirements Specification (SRS)
- User Stories
- Use Case Diagram
- UI/UX Designs
- Trello Project Management
- Final Project Report

## Project Management

The project is managed using Trello for task tracking and
GitHub for version control and collaboration.
